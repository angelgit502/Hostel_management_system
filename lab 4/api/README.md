# HMS Express.js API Folder

This folder will house Express.js routes, controllers, and middleware for backend integration.

### Planned Endpoints:
- `POST /api/auth/login` - User authentication
- `POST /api/auth/register` - Student/Staff registration
- `GET /api/students` - Retrieve student list
- `POST /api/students` - Add new student
- `GET /api/rooms` - Room occupancy status
- `POST /api/rooms/allocate` - Room allocation
- `GET /api/complaints` - List complaints
- `POST /api/complaints` - Submit complaint ticket
- `PUT /api/complaints/:id/resolve` - Resolve complaint ticket
